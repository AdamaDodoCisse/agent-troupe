# agent-troupe

A live, local web page with animated characters showing your Claude agents at work and the messages they exchange. Seven roles with clear definitions (PO, Business Analyst, IT Owner, Tech Lead, Developer, Reviewer, QA) and four team templates. Everything stays on your machine (`127.0.0.1`).

Install: `/plugin install agent-troupe --marketplace AdamaDodoCisse/agent-troupe` (Node.js 18 or later required).

Type `/troupe` for the page address, `/troupe open` to open it, then delegate with `agent-troupe:<role>`. Full documentation, roles table and configuration: see the repository README at the root.
